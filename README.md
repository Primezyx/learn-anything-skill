# learn-anything · 学会任何知识

一个中文友好的 Codex Skill，把学习目标转成可练习、可检验、可复习的过程。按需求选择学习模式，也可以串联成完整学习流程。

## 六种模式

| 模式 | 用途 |
| --- | --- |
| 学习阶梯 | 从初识到独立实践，明确每级的练习与晋级证据。 |
| 集中练习计划 | 默认安排 20 小时练习，并按实际时间预算调整。 |
| 主动回忆测验 | 一次一题，依据实际作答反馈、评分和查漏补缺。 |
| 一页速查 | 整理核心概念、短例、易错点和自检题。 |
| 资源筛选 | 核实并筛选学习资源，安排有具体产出的学习路径。 |
| 费曼复述 | 用浅显解释与自己的话复述，找到并补齐理解缺口。 |

## 安装

下载本仓库并解压，将包含 `SKILL.md` 的文件夹命名为 `learn-anything`，放入 Codex 的个人技能目录 `~/.codex/skills/`。最终结构应为：

```text
~/.codex/skills/learn-anything/
├── SKILL.md
├── README.md
└── agents/
    └── openai.yaml
```

Windows 中的 `~` 表示当前用户目录。若设置了 `CODEX_HOME`，则使用该目录下的 `skills/`。

## 调用示例

- `使用 $learn-anything，带我从零学习 Python，每天一小时。`
- `使用 $learn-anything，我零基础学 SQL，希望二十小时后能做月度销售分析。`
- `用 $learn-anything 考我概率论，一次一题，先别告诉我答案。`
- `用 $learn-anything 做一页 Git 分支速查表。`
- `使用 $learn-anything 的费曼复述模式，带我理解梯度下降。`

只说“带我学习”时，会先给简短路径和第一项活动；无需一次使用所有模式。学习效果通过作答或作品检验，不承诺“十倍速”或短期成为专家。

## 文件

- [SKILL.md](SKILL.md)：触发条件、六种学习模式与执行规则。
- [agents/openai.yaml](agents/openai.yaml)：名称、描述和默认调用提示。
