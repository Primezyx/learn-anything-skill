# 在讲解段落中嵌入实时交互网页

## 先决定让读者操作什么

从当前知识点选一个小例子，补全：“读者改变 ___ 或推进一步，会看到 ___ 改变，因为 ___。”没有值得操作的变化，就用文字或静态图。把一句观察提示放在控件前，规律和适用前提放在控件后；不操作也能读懂。

| 难点 | 读者操作与可见变化 | 保持不变的参照 |
| --- | --- | --- |
| 二分查找 | 改目标值，逐次比较，观察候选区间收缩 | 有序数组、索引和边界标签 |
| 消息流 | 推进一步，查看同一条消息的位置和内容 | 节点顺序和消息标识 |
| 函数与参数 | 调一个参数，看点或曲线如何移动 | 坐标尺度、单位和基准线 |

默认停在起点，无声、不自动循环。允许步进、播放、暂停、重播和改变目标值；目标改变时从新输入重算，而不是切换录像。图与正文使用相同的变量、数值和单位；除颜色外，再用文字或形状标明变化。离散状态按步切换，不画出不存在的中间值。

## 选择实现与交付方式

- 简单机制：直接用 HTML/CSS/SVG/JS，让控件更新状态并重绘图形，不需要构建工具。
- 复杂时间轴：用 Remotion Player 随时间推进 SVG/DOM，并让用户输入参与状态计算。不要导出视频或 GIF，也不要在网页里嵌播放器播放预录内容。
- 优先让读者在对应讲解段落内直接操作。宿主不支持内嵌时，在原处提供独立 HTML 附件；不要只贴源码或开发服务器地址。缺少 Node.js、依赖或构建权限时，先改做原生交互网页，不直接降为静态图。宿主禁止脚本时才用带标签的静态步骤，并说明限制。

## 复杂时间轴：从模板构建独立 HTML

将 `assets/remotion-lesson/` 整个复制到本次课程工作区的独立目录。只修改副本，不改技能模板或其他课程。按当前例子调整以下文件：

| 文件 | 职责 |
| --- | --- |
| `package.json` | 声明依赖和构建命令 |
| `lesson.jsx` | 定义示例状态、状态转移及对应的 SVG 图 |
| `index.jsx` | 挂载页面，连接输入、步进和播放控件 |
| `page.html` | 提供页面样式与无 JS 时可读的静态说明 |
| `build.mjs` | 将脚本和依赖内联到单个 HTML |

在副本内执行；仅在获准安装依赖时运行第一条命令：

```sh
npm install --no-audit --no-fund
npm run build
```

交付文件为 `dist/lesson.html`。验收时断网、不开服务器，直接双击该文件：确认无须 Node.js 即可观看；初始画面不动，步进时图与说明同步；改目标值后比较路径随之更新；暂停留在当前状态，重播返回本次输入的起点。另检查无脚本时的说明是否足以理解。未实际检查的行为不声称已验证。

测验或复述题出题后先等用户作答，不在控件、可展开步骤或无脚本说明中预放答案。纠错时只放已答部分，不因点击“下一步”泄露后续题目。
